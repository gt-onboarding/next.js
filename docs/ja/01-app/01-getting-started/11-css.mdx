## Tailwind CSS

[Tailwind CSS](https://tailwindcss.com/) は、カスタムデザインを構築するための低レベルなユーティリティクラスを提供する、ユーティリティファースト CSS フレームワークです。

<AppOnly>

Tailwind CSS をインストールします：

```bash package="pnpm"
pnpm add -D tailwindcss @tailwindcss/postcss
```

```bash package="npm"
npm install -D tailwindcss @tailwindcss/postcss
```

```bash package="yarn"
yarn add -D tailwindcss @tailwindcss/postcss
```

```bash package="bun"
bun add -D tailwindcss @tailwindcss/postcss
```

`postcss.config.mjs` ファイルに PostCSS プラグインを追加します：

```js filename="postcss.config.mjs"
export default {
  plugins: {
    '@tailwindcss/postcss': {},
  },
}
```

グローバル CSS ファイルに Tailwind をインポートします：

```css filename="app/globals.css"
@import 'tailwindcss';
```

ルートレイアウトで CSS ファイルをインポートします：

```tsx filename="app/layout.tsx" switcher
import './globals.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import './globals.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

これで、アプリケーション内で Tailwind のユーティリティクラスを使い始めることができます：

```tsx filename="app/page.tsx" switcher
export default function Page() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <h1 className="text-4xl font-bold">Welcome to Next.js!</h1>
    </main>
  )
}
```

```jsx filename="app/page.js" switcher
export default function Page() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <h1 className="text-4xl font-bold">Welcome to Next.js!</h1>
    </main>
  )
}
```

</AppOnly>

## CSS Modules

CSS Modules は、ユニークなクラス名を生成することで CSS をローカルにスコープします。これにより、異なるファイルで同じクラス名を名前の衝突を気にせずに使用できます。

<AppOnly>

CSS Modules を使用するには、拡張子が `.module.css` の新しいファイルを作成し、`app` ディレクトリ内の任意のコンポーネントにインポートします:

```css filename="app/blog/blog.module.css"
.blog {
  padding: 24px;
}
```

```tsx filename="app/blog/page.tsx" switcher
import styles from './blog.module.css'

export default function Page() {
  return <main className={styles.blog}></main>
}
```

```jsx filename="app/blog/page.js" switcher
import styles from './blog.module.css'

export default function Layout() {
  return <main className={styles.blog}></main>
}
```

</AppOnly>

<PagesOnly>

CSS Modules を使用するには、拡張子が `.module.css` の新しいファイルを作成し、`pages` ディレクトリ内の任意のコンポーネントにインポートします:

```css filename="/styles/blog.module.css"
.blog {
  padding: 24px;
}
```

```tsx filename="pages/blog/index.tsx" switcher
import styles from './blog.module.css'

export default function Page() {
  return <main className={styles.blog}></main>
}
```

```jsx filename="pages/blog/index.js" switcher
import styles from './blog.module.css'

export default function Page() {
  return <main className={styles.blog}></main>
}
```

</PagesOnly>

## グローバル CSS

アプリケーション全体にスタイルを適用するには、グローバル CSS を使用できます。

<AppOnly>

`app/global.css` ファイルを作成し、ルートレイアウトでインポートすると、アプリケーション内の **すべてのルート** にスタイルを適用できます:

```css filename="app/global.css"
body {
  padding: 20px 20px 60px;
  max-width: 680px;
  margin: 0 auto;
}
```

```tsx filename="app/layout.tsx" switcher
// これらのスタイルはアプリケーション内のすべてのルートに適用されます
import './global.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
// これらのスタイルはアプリケーション内のすべてのルートに適用されます
import './global.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

> **補足:** グローバルスタイルは、`app` ディレクトリ内の任意の layout、page、component にインポートできます。ただし、Next.js は Suspense と統合するためにスタイルシートに対する React の組み込みサポートを使用しているため、現時点ではルート間を移動してもスタイルシートは削除されず、競合を引き起こす可能性があります。本当にグローバルな CSS (Tailwind のベーススタイルなど) にはグローバルスタイルを使用し、コンポーネントのスタイリングには [Tailwind CSS](#tailwind-css)、必要に応じてカスタムなスコープ付き CSS には [CSS Modules](#css-modules) の使用を推奨します。

</AppOnly>

<PagesOnly>

アプリケーション内の **すべてのルート** にスタイルを適用するには、`pages/_app.js` ファイル内でスタイルシートをインポートします:

```tsx filename="pages/_app.js"
import '@/styles/global.css'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

スタイルシートはグローバルな性質を持つため、競合を避けるためにも、[`pages/_app.js`](/docs/pages/building-your-application/routing/custom-app) 内でインポートする必要があります。

</PagesOnly>

## 外部スタイルシート

<AppOnly>

外部パッケージによって公開されているスタイルシートは、`app` ディレクトリ内の任意の場所（同一ディレクトリにあるコンポーネントなどのコロケーションされたコンポーネントを含む）でインポートできます:

```tsx filename="app/layout.tsx" switcher
import 'bootstrap/dist/css/bootstrap.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body className="container">{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import 'bootstrap/dist/css/bootstrap.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body className="container">{children}</body>
    </html>
  )
}
```

> **補足:** React 19 では、`<link rel="stylesheet" href="..." />` も使用できます。詳しくは [React `link` のドキュメント](https://react.dev/reference/react-dom/components/link) を参照してください。

</AppOnly>

<PagesOnly>

Next.js では、JavaScript ファイルから CSS ファイルをインポートできます。これは、Next.js が JavaScript の [`import`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Statements/import) 構文の概念を拡張しているためです。

### `node_modules` からスタイルをインポートする

Next.js **9.5.4** 以降では、`node_modules` から CSS ファイルをアプリケーション内の任意の場所でインポートできます。

`bootstrap` や `nprogress` のようなグローバルなスタイルシートの場合は、`pages/_app.js` 内でファイルをインポートすることを推奨します。例:

```jsx filename="pages/_app.js"
import 'bootstrap/dist/css/bootstrap.css'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

サードパーティコンポーネントに必要な CSS をインポートするには、そのコンポーネント内でインポートできます。例:

```jsx filename="components/example-dialog.js"
import { useState } from 'react'
import { Dialog } from '@reach/dialog'
import VisuallyHidden from '@reach/visually-hidden'
import '@reach/dialog/styles.css'

function ExampleDialog(props) {
  const [showDialog, setShowDialog] = useState(false)
  const open = () => setShowDialog(true)
  const close = () => setShowDialog(false)

  return (
    <div>
      <button onClick={open}>Open Dialog</button>
      <Dialog isOpen={showDialog} onDismiss={close}>
        <button className="close-button" onClick={close}>
          <VisuallyHidden>Close</VisuallyHidden>
          <span aria-hidden>×</span>
        </button>
        <p>Hello there. I am a dialog</p>
      </Dialog>
    </div>
  )
}
```

</PagesOnly>

## 並び順とマージ

Next.js は本番ビルド時にスタイルシートを自動的にチャンク化（マージ）して CSS を最適化します。**CSS の並び順**は、**コード内でスタイルをインポートする順序**によって決まります。

たとえば、`<BaseButton>` を `page.module.css` より先にインポートしている場合、`base-button.module.css` は `page.module.css` より前に配置されます:

```tsx filename="page.tsx" switcher
import { BaseButton } from './base-button'
import styles from './page.module.css'

export default function Page() {
  return <BaseButton className={styles.primary} />
}
```

```jsx filename="page.js" switcher
import { BaseButton } from './base-button'
import styles from './page.module.css'

export default function Page() {
  return <BaseButton className={styles.primary} />
}
```

```tsx filename="base-button.tsx" switcher
import styles from './base-button.module.css'

export function BaseButton() {
  return <button className={styles.primary} />
}
```

```jsx filename="base-button.js" switcher
import styles from './base-button.module.css'

export function BaseButton() {
  return <button className={styles.primary} />
}
```

### 推奨事項

CSS の適用順序を予測しやすく保つには、次の点を守ってください:

- CSS のインポートは、できるだけ 1 つの JavaScript または TypeScript エントリーファイルにまとめる
- グローバルスタイルと Tailwind のスタイルシートは、アプリケーションルートでインポートする
- ユーティリティクラスで一般的なデザインパターンを網羅しているため、スタイルの大半には **Tailwind CSS を使用** する
- Tailwind のユーティリティだけでは不十分な場合は、コンポーネント固有のスタイルに CSS Modules を使用する
- CSS Modules には一貫した命名規則を使用する。たとえば `<name>.tsx` ではなく `<name>.module.css` を使用する
- 重複したインポートを避けるために、共通スタイルは共通コンポーネントとして切り出す
- ESLint の [`sort-imports`](https://eslint.org/docs/latest/rules/sort-imports) のように、インポートを自動ソートするリンターやフォーマッターはオフにする
- `next.config.js` の [`cssChunking`](/docs/app/api-reference/config/next-config-js/cssChunking) オプションを使用して、CSS の分割方法を制御できる

## 開発環境と本番環境

- 開発環境（`next dev`）では、CSS の更新は [Fast Refresh](/docs/architecture/fast-refresh) によって即座に反映されます。
- 本番環境（`next build`）では、すべての CSS ファイルが自動的に連結され、**多数の圧縮およびコード分割された** `.css` ファイルとなり、各ルートで読み込まれる CSS 量が最小限になるよう最適化されます。
- 本番環境では JavaScript が無効でも CSS は読み込まれますが、開発環境では Fast Refresh のために JavaScript が必要です。
- CSS の読み込み順序は開発環境と本番環境で異なる場合があるため、必ずビルド（`next build`）を確認して最終的な CSS の順序を検証してください。
