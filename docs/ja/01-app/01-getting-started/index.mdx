Next.js のドキュメントへようこそ。

この **はじめに** セクションでは、最初の Next.js アプリを作成し、あらゆるプロジェクトで使用する中核的な機能について学びます。

## 前提知識

本ドキュメントでは、読者がある程度の Web 開発の知識を持っていることを前提としています。始める前に、次の内容に慣れていると役に立ちます。

- HTML
- CSS
- JavaScript
- React

React を初めて扱う場合や復習が必要な場合は、まず [React Foundations コース](/learn/react-foundations)と、学びながら実際にアプリケーションを構築していく [Next.js Foundations コース](/learn/dashboard-app) から始めることをおすすめします。
