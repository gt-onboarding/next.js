このガイドでは、Next.js アプリケーションに [Tailwind CSS v3](https://v3.tailwindcss.com/) をインストールする方法を順を追って説明します。

> **補足:** 最新の Tailwind 4 のセットアップについては、[Tailwind CSS のセットアップ手順](/docs/app/getting-started/css#tailwind-css)を参照してください。

## Tailwind v3 のインストール

Tailwind CSS とそのピア依存パッケージをインストールし、その後 `init` コマンドを実行して、`tailwind.config.js` と `postcss.config.js` の両方を生成します。

```bash package="pnpm"
pnpm add -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
```

```bash package="npm"
npm install -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
```

```bash package="yarn"
yarn add -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
```

```bash package="bun"
bun add -D tailwindcss@^3 postcss autoprefixer
bunx tailwindcss init -p
```

## Tailwind v3 の設定

`tailwind.config.js` ファイルでテンプレートのパスを設定します：

<AppOnly>

```js filename="tailwind.config.js"
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    './app/**/*.{js,ts,jsx,tsx,mdx}',
    './pages/**/*.{js,ts,jsx,tsx,mdx}',
    './components/**/*.{js,ts,jsx,tsx,mdx}',
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

Tailwind のディレクティブをグローバルCSSファイルに追加します：

```css filename="app/globals.css"
@tailwind base;
@tailwind components;
@tailwind utilities;
```

ルートレイアウトでこのCSSファイルをインポートします：

```tsx filename="app/layout.tsx" switcher
import './globals.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import './globals.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

</AppOnly>

<PagesOnly>

```js filename="tailwind.config.js"
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    './pages/**/*.{js,ts,jsx,tsx,mdx}',
    './components/**/*.{js,ts,jsx,tsx,mdx}',
    './app/**/*.{js,ts,jsx,tsx,mdx}',
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

Tailwind のディレクティブをグローバルCSSファイルに追加します：

```css filename="styles/globals.css"
@tailwind base;
@tailwind components;
@tailwind utilities;
```

`pages/_app.js` ファイルでこのCSSファイルをインポートします：

```jsx filename="pages/_app.js"
import '@/styles/globals.css'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

</PagesOnly>

## クラスの利用

Tailwind CSS をインストールしてグローバルスタイルを追加すると、アプリケーション内で Tailwind のユーティリティクラスを使えるようになります。

<AppOnly>

```tsx filename="app/page.tsx" switcher
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>
}
```

```jsx filename="app/page.js" switcher
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>
}
```

</AppOnly>

<PagesOnly>

```tsx filename="pages/index.tsx" switcher
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>
}
```

```jsx filename="pages/index.js" switcher
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>
}
```

</PagesOnly>

## Turbopack での使用

Next.js 13.1 以降、Tailwind CSS と PostCSS は [Turbopack](https://turbo.build/pack/docs/features/css#tailwind-css) で利用できます。
