`favicon`、`icon`、`apple-icon` のファイル規約を使うと、アプリケーションのアイコンを設定できます。

これらは、ウェブブラウザのタブ、スマートフォンのホーム画面、検索エンジンの結果などに表示されるアプリアイコンを追加するのに役立ちます。

アプリアイコンを設定する方法は 2 つあります。

- [画像ファイルを使用する (.ico, .jpg, .png)](#image-files-ico-jpg-png)
- [コードを使ってアイコンを生成する (.js, .ts, .tsx)](#generate-icons-using-code-js-ts-tsx)

## 画像ファイル (.ico, .jpg, .png)

`/app` ディレクトリ内に `favicon`、`icon`、または `apple-icon` の画像ファイルを配置することで、アプリのアイコンを設定できます。
`favicon` 画像は `app/` 直下にのみ配置できます。

Next.js はファイルを解析し、アプリの `<head>` 要素に適切なタグを自動的に追加します。

| ファイル命名規則            | サポートされるファイルタイプ            | 有効な配置場所 |
| --------------------------- | --------------------------------------- | -------------- |
| [`favicon`](#favicon)       | `.ico`                                  | `app/`         |
| [`icon`](#icon)             | `.ico`, `.jpg`, `.jpeg`, `.png`, `.svg` | `app/**/*`     |
| [`apple-icon`](#apple-icon) | `.jpg`, `.jpeg`, `.png`                 | `app/**/*`     |

### `favicon`

`favicon.ico` 画像ファイルを `/app` のルートセグメント直下に追加します。

```html filename="<head> output"
<link rel="icon" href="/favicon.ico" sizes="any" />
```

### `icon`

`icon.(ico|jpg|jpeg|png|svg)` 形式の画像ファイルを追加します。

```html filename="<head> output"
<link
  rel="icon"
  href="/icon?<generated>"
  type="image/<generated>"
  sizes="<generated>"
/>
```

### `apple-icon`

`apple-icon.(jpg|jpeg|png)` という画像ファイルを追加してください。

```html filename="<head> output"
<link
  rel="apple-touch-icon"
  href="/apple-icon?<generated>"
  type="image/<generated>"
  sizes="<generated>"
/>
```

> **補足**:
>
> - ファイル名に番号付きのサフィックスを追加することで、複数のアイコンを設定できます。例えば、`icon1.png`、`icon2.png` などです。番号付きファイルは辞書順でソートされます。
> - Favicon はルートの `/app` セグメントでのみ設定できます。より細かく制御する必要がある場合は、[`icon`](#icon) を使用できます。
> - 適切な `<link>` タグと `rel`、`href`、`type`、`sizes` などの属性は、対象ファイルのアイコンの種類とメタデータによって決定されます。
> - 例えば、32×32px の `.png` ファイルには、`type="image/png"` と `sizes="32x32"` の属性が設定されます。
> - 拡張子が `.svg` の場合、またはファイルの画像サイズが判別できない場合は、`sizes="any"` がアイコンに追加されます。詳細については、この [favicon handbook](https://evilmartians.com/chronicles/how-to-favicon-in-2021-six-files-that-fit-most-needs) を参照してください。

## コードを使ってアイコンを生成する (.js, .ts, .tsx)

[画像ファイルそのもの](#image-files-ico-jpg-png)を使う方法に加えて、コードでアイコンを**生成**することもできます。

`icon` または `apple-icon` ルートを作成し、関数をデフォルトエクスポートすることでアプリアイコンを生成します。

| ファイル命名規則 | 対応ファイルタイプ   |
| ---------------- | -------------------- |
| `icon`           | `.js`, `.ts`, `.tsx` |
| `apple-icon`     | `.js`, `.ts`, `.tsx` |

アイコンを生成する最も簡単な方法は、`next/og` の [`ImageResponse`](/docs/app/api-reference/functions/image-response) API を使用することです。

```tsx filename="app/icon.tsx" switcher
import { ImageResponse } from 'next/og'

// 画像メタデータ
export const size = {
  width: 32,
  height: 32,
}
export const contentType = 'image/png'

// 画像生成
export default function Icon() {
  return new ImageResponse(
    (
      // ImageResponse JSX要素
      <div
        style={{
          fontSize: 24,
          background: 'black',
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          color: 'white',
        }}
      >
        A
      </div>
    ),
    // ImageResponseのオプション
    {
      // 便宜上、エクスポートされたアイコンのサイズメタデータの設定を
      // ImageResponseのwidthとheightにも再利用できます。
      ...size,
    }
  )
}
```

```jsx filename="app/icon.js" switcher
import { ImageResponse } from 'next/og'

// 画像メタデータ
export const size = {
  width: 32,
  height: 32,
}
export const contentType = 'image/png'

// 画像生成
export default function Icon() {
  return new ImageResponse(
    (
      // ImageResponse JSX 要素
      <div
        style={{
          fontSize: 24,
          background: 'black',
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          color: 'white',
        }}
      >
        A
      </div>
    ),
    // ImageResponse オプション
    {
      // 便宜上、エクスポートされたアイコンのサイズメタデータの設定を
      // ImageResponse の width と height にも流用できます。
      ...size,
    }
  )
}
```

```html filename="<head> output"
<link rel="icon" href="/icon?<generated>" type="image/png" sizes="32x32" />
```

> **補足**:
>
> - 生成されたアイコンは、[**静的に最適化**](/docs/app/guides/caching#static-rendering)（ビルド時に生成されキャッシュされる）されるのがデフォルトです。ただし、[Dynamic APIs](/docs/app/guides/caching#dynamic-rendering) やキャッシュされていないデータを使用する場合は除きます。
> - 同じファイル内で複数のアイコンを [`generateImageMetadata`](/docs/app/api-reference/functions/generate-image-metadata) を使って生成できます。
> - `favicon` アイコンを生成することはできません。代わりに [`icon`](#icon) か [favicon.ico](#favicon) ファイルを使用してください。
> - App アイコンは特別な Route Handler であり、[Dynamic API](/docs/app/guides/caching#dynamic-apis) や [dynamic config](/docs/app/guides/caching#segment-config-options) オプションを使用しない限り、デフォルトでキャッシュされます。

### Props

デフォルトエクスポートの関数は、次の props を受け取ります。

#### `params` (optional)

ルートセグメントから、`icon` または `apple-icon` が配置されているセグメントまでの [動的ルートパラメータ](/docs/app/api-reference/file-conventions/dynamic-routes) オブジェクトを含むオブジェクトへと解決される Promise です。

> **補足**: [`generateImageMetadata`](/docs/app/api-reference/functions/generate-image-metadata) を使用する場合、この関数は `generateImageMetadata` が返すアイテムのいずれかの `id` 値へと解決される Promise である `id` プロップも受け取ります。

```tsx filename="app/shop/[slug]/icon.tsx" switcher
export default async function Icon({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
  // ...
}
```

```jsx filename="app/shop/[slug]/icon.js" switcher
export default async function Icon({ params }) {
  const { slug } = await params
  // ...
}
```

| ルート                          | URL         | `params`（パラメータ）             |
| ------------------------------- | ----------- | ---------------------------------- |
| `app/shop/icon.js`              | `/shop`     | `undefined`                        |
| `app/shop/[slug]/icon.js`       | `/shop/1`   | `Promise<{ slug: '1' }>`           |
| `app/shop/[tag]/[item]/icon.js` | `/shop/1/2` | `Promise<{ tag: '1', item: '2' }>` |

### 戻り値

デフォルトエクスポート関数は `Blob` | `ArrayBuffer` | `TypedArray` | `DataView` | `ReadableStream` | `Response` を返す必要があります。

> **補足**: `ImageResponse` はこの戻り値型を満たします。

### 設定のエクスポート

`icon` または `apple-icon` ルートから `size` と `contentType` 変数をエクスポートすることで、必要に応じてアイコンのメタデータを設定できます。

| オプション                    | 型                                                                                                                 |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| [`size`](#size)               | `{ width: number; height: number }`                                                                                |
| [`contentType`](#contenttype) | `string` - [画像の MIME タイプ](https://developer.mozilla.org/docs/Web/HTTP/Basics_of_HTTP/MIME_types#image_types) |

#### `size`

```tsx filename="icon.tsx | apple-icon.tsx" switcher
export const size = { width: 32, height: 32 }

export default function Icon() {}
```

```jsx filename="icon.js | apple-icon.js" switcher
export const size = { width: 32, height: 32 }

export default function Icon() {}
```

```html filename="<head> output"
<link rel="icon" sizes="32x32" />
```

#### `contentType`

```tsx filename="icon.tsx | apple-icon.tsx" switcher
export const contentType = 'image/png'

export default function Icon() {}
```

```jsx filename="icon.js | apple-icon.js" switcher
export const contentType = 'image/png'

export default function Icon() {}
```

```html filename="<head> output"
<link rel="icon" type="image/png" />
```

#### ルートセグメントの設定

`icon` と `apple-icon` は、Pages や Layouts と同じ [ルートセグメント設定](/docs/app/api-reference/file-conventions/route-segment-config) オプションを使用できる、専用の [Route Handlers](/docs/app/api-reference/file-conventions/route) です。
