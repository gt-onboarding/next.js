ブラウザに Web アプリケーションの情報を提供できるようにするため、`app` ディレクトリの**ルート**に [Web Manifest 仕様](https://developer.mozilla.org/docs/Web/Manifest) に準拠した `manifest.(json|webmanifest)` ファイルを追加または生成します。

## 静的マニフェストファイル

```json filename="app/manifest.json | app/manifest.webmanifest"
{
  "name": "My Next.js Application",
  "short_name": "Next.js App",
  "description": "An application built with Next.js",
  "start_url": "/"
  // ...
}
```

## Manifest ファイルを生成する

[`Manifest` オブジェクト](#manifest-object) を返す `manifest.js` または `manifest.ts` ファイルを追加します。

> 補足: `manifest.js` は特別な Route Handler であり、[Dynamic API](/docs/app/guides/caching#dynamic-apis) や [dynamic config](/docs/app/guides/caching#segment-config-options) オプションを使用している場合を除き、デフォルトでキャッシュされます。

```ts filename="app/manifest.ts" switcher
import type { MetadataRoute } from 'next'

export default function manifest(): MetadataRoute.Manifest {
  return {
    name: 'Next.js App',
    short_name: 'Next.js App',
    description: 'Next.js App',
    start_url: '/',
    display: 'standalone',
    background_color: '#fff',
    theme_color: '#fff',
    icons: [
      {
        src: '/favicon.ico',
        sizes: 'any',
        type: 'image/x-icon',
      },
    ],
  }
}
```

```js filename="app/manifest.js" switcher
export default function manifest() {
  return {
    name: 'Next.js App',
    short_name: 'Next.js App',
    description: 'Next.js App',
    start_url: '/',
    display: 'standalone',
    background_color: '#fff',
    theme_color: '#fff',
    icons: [
      {
        src: '/favicon.ico',
        sizes: 'any',
        type: 'image/x-icon',
      },
    ],
  }
}
```

### Manifest オブジェクト

Manifest オブジェクトには、多数のオプションが含まれており、新しい Web 標準の策定に伴い更新される可能性があります。現在利用可能なすべてのオプションについては、[TypeScript](/docs/app/api-reference/config/typescript#ide-plugin) を使用している場合はコードエディタ内の `MetadataRoute.Manifest` 型を参照するか、[MDN](https://developer.mozilla.org/docs/Web/Manifest) のドキュメントを参照してください。
