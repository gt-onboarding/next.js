`usePathname` は、現在の URL の **pathname** を取得できる **Client Component** フックです。

> **補足**: [`cacheComponents`](/docs/app/api-reference/config/next-config-js/cacheComponents) が有効になっている場合、ルートに動的パラメータがあると `usePathname` の周りに `Suspense` の境界が必要になることがあります。`generateStaticParams` を使用する場合、`Suspense` の境界は任意です。

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { usePathname } from 'next/navigation'

export default function ExampleClientComponent() {
  const pathname = usePathname()
  return <p>Current pathname: {pathname}</p>
}
```

```jsx filename="app/example-client-component.js" switcher
'use client'

import { usePathname } from 'next/navigation'

export default function ExampleClientComponent() {
  const pathname = usePathname()
  return <p>Current pathname: {pathname}</p>
}
```

`usePathname` は意図的に [クライアントコンポーネント](/docs/app/getting-started/server-and-client-components) での使用を必要とします。クライアントコンポーネントはパフォーマンスを損なうものではありません。クライアントコンポーネントは [サーバーコンポーネント](/docs/app/getting-started/server-and-client-components) アーキテクチャを構成する不可欠な要素です。

例えば、`usePathname` を使うクライアントコンポーネントは、初回のページロード時に HTML にレンダーされます。新しいルートへナビゲートした際、このコンポーネントを再フェッチする必要はありません。代わりに、このコンポーネントは一度だけ（クライアントの JavaScript バンドル内に）ダウンロードされ、現在の state（状態）に基づいて再レンダーされます。

> **補足**:
>
> - 現在の URL を [サーバーコンポーネント](/docs/app/getting-started/server-and-client-components) から読み取ることはサポートされていません。この設計は、ページ間のナビゲーションをまたいでレイアウトの state（状態）を保持できるようにするための、意図的なものです。
> - ページが静的に事前レンダーされていて、アプリに `next.config` 内の [rewrites](/docs/app/api-reference/config/next-config-js/rewrites) や [Proxy](/docs/app/api-reference/file-conventions/proxy) ファイルがある場合、`usePathname()` で pathname を読み取るとハイドレーションの不整合エラーが発生することがあります。これは、初期値がサーバーから来ており、ルーティング後の実際のブラウザの pathname と一致しない可能性があるためです。この問題を軽減する方法については [こちらの例](#avoid-hydration-mismatch-with-rewrites) を参照してください。

<details>
  <summary>Pages Router との互換性</summary>

`usePathname` を使用するコンポーネントを Pages Router 内のルートにインポートしている場合、ルーターがまだ初期化されていないときには `usePathname` が `null` を返す可能性があることに注意してください。これは、[fallback ルート](/docs/pages/api-reference/functions/get-static-paths#fallback-true) や、Pages Router における [Automatic Static Optimization](https://nextjs.org/docs/pages/building-your-application/rendering/static#automatic-static-optimization) などのケースで発生することがあります。

ルーティングシステム間の互換性を高めるため、プロジェクトに `app` ディレクトリと `pages` ディレクトリの両方が存在する場合、Next.js は `usePathname` の戻り値の型を自動的に調整します。

</details>

## 引数

```tsx
const pathname = usePathname()
```

`usePathname` は引数を取りません。

## 返り値

`usePathname` は現在の URL のパス名を表す文字列を返します。例えば次のとおりです:

| URL                 | 返される値            |
| ------------------- | --------------------- |
| `/`                 | `'/'`                 |
| `/dashboard`        | `'/dashboard'`        |
| `/dashboard?v=2`    | `'/dashboard'`        |
| `/blog/hello-world` | `'/blog/hello-world'` |

## 使用例

### ルート変更時に何かを実行する

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useEffect } from 'react'
import { usePathname, useSearchParams } from 'next/navigation'

function ExampleClientComponent() {
  const pathname = usePathname()
  const searchParams = useSearchParams()
  useEffect(() => {
    // ここで何か処理を行う...
  }, [pathname, searchParams])
}
```

```jsx filename="app/example-client-component.js" switcher

import { useEffect } from 'react'

function ExampleClientComponent() {
  const pathname = usePathname()
  const searchParams = useSearchParams()

    // ここで何かを実行する...
  }, [pathname, searchParams])
}
```

### リライト時のハイドレーション不整合を避ける

ページがプリレンダリングされるとき、HTML は元のパス名に対して生成されます。その後、`next.config` や `Proxy` を使ったリライト経由でページに到達した場合、ブラウザの URL は異なる可能性があり、クライアント側の `usePathname()` はリライト後のパス名を読み取ります。

ハイドレーションの不整合を避けるには、クライアントのパス名に依存する部分を、小さく分離された UI の一部に限定するよう設計します。サーバー側では安定したフォールバックをレンダーし、マウント後にその部分のみを更新します。

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useEffect, useState } from 'react'
import { usePathname } from 'next/navigation'

export default function PathnameBadge() {
  const pathname = usePathname()
  const [clientPathname, setClientPathname] = useState('')

  useEffect(() => {
    setClientPathname(pathname)
  }, [pathname])

  return (
    <p>
      現在のパス名: <span>{clientPathname}</span>
    </p>
  )
}
```

```jsx filename="app/example-client-component.js" switcher
'use client'

import { useEffect, useState } from 'react'
import { usePathname } from 'next/navigation'

export default function PathnameBadge() {
  const pathname = usePathname()
  const [clientPathname, setClientPathname] = useState('')

  useEffect(() => {
    setClientPathname(pathname)
  }, [pathname])

  return (
    <p>
      Current pathname: <span>{clientPathname}</span>
    </p>
  )
}
```
