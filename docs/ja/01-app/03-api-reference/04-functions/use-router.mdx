`useRouter` フックを使用すると、[Client Components](/docs/app/getting-started/server-and-client-components) 内でルートをプログラムから変更できます。

> **推奨:** 特別な要件がない限り、ナビゲーションには [`<Link>` コンポーネント](/docs/app/api-reference/components/link) を使用してください。

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useRouter } from 'next/navigation'

export default function Page() {
  const router = useRouter()

  return (
    <button type="button" onClick={() => router.push('/dashboard')}>
      Dashboard
    </button>
  )
}
```

```jsx filename="app/example-client-component.js" switcher
'use client'

import { useRouter } from 'next/navigation'

export default function Page() {
  const router = useRouter()

  return (
    <button type="button" onClick={() => router.push('/dashboard')}>
      Dashboard
    </button>
  )
}
```

## `useRouter()`

- `router.push(href: string, { scroll: boolean })`: 指定したルートへクライアントサイドナビゲーションを実行します。[ブラウザーの履歴スタック](https://developer.mozilla.org/docs/Web/API/History_API)に新しいエントリーを追加します。
- `router.replace(href: string, { scroll: boolean })`: 指定したルートへクライアントサイドナビゲーションを実行しますが、ブラウザーの履歴スタックに新しいエントリーは追加しません。
- `router.refresh()`: 現在のルートをリフレッシュします。サーバーへの新しいリクエストを行い、データリクエストを再フェッチし、サーバーコンポーネントを再レンダーします。クライアント側では、影響を受けないクライアントサイドの React（例: `useState`）やブラウザー状態（例: スクロール位置）を失うことなく、更新されたサーバーコンポーネントのペイロードをマージします。
- `router.prefetch(href: string, options?: { onInvalidate?: () => void })`: より高速なクライアントサイド遷移のために、指定したルートを[プリフェッチ](/docs/app/getting-started/linking-and-navigating#prefetching)します。オプションの `onInvalidate` コールバックは、[プリフェッチされたデータが古くなったとき](/docs/app/guides/prefetching#extending-or-ejecting-link)に呼び出されます。
- `router.back()`: ブラウザーの履歴スタック内で前のルートに戻ります。
- `router.forward()`: ブラウザーの履歴スタック内で次のページに進みます。

> **補足**:
>
> - 信頼できない、またはサニタイズされていない URL を `router.push` や `router.replace` に渡してはいけません。クロスサイトスクリプティング（XSS）の脆弱性につながる可能性があります。たとえば、`javascript:` URL を `router.push` や `router.replace` に渡すと、そのページのコンテキストで実行されます。
> - `<Link>` コンポーネントは、ビューポート内で可視になったタイミングで自動的にルートをプリフェッチします。
> - フェッチリクエストがキャッシュされている場合、`refresh()` は同じ結果を再生成する可能性があります。`cookies` や `headers` といった他の動的 API によってもレスポンスが変化することがあります。
> - `onInvalidate` コールバックは、プリフェッチリクエストごとに最大一度だけ呼び出されます。これは、更新されたルートデータに対して新しいプリフェッチをトリガーすべきタイミングを知らせるシグナルです。

### `next/router` からの移行

- App Router を使用する場合、`useRouter` フックは `next/router` ではなく `next/navigation` からインポートする必要があります
- `pathname` 文字列は削除され、代わりに [`usePathname()`](/docs/app/api-reference/functions/use-pathname) を使用します
- `query` オブジェクトは削除され、代わりに [`useSearchParams()`](/docs/app/api-reference/functions/use-search-params) を使用します
- `router.events` は置き換えられました。[以下を参照してください。](#router-events)

[完全な移行ガイドを参照してください](/docs/app/guides/migrating/app-router-migration)

## 使用例

### ルーターイベント

`usePathname` や `useSearchParams` などの他の Client Component フックを組み合わせて、ページの変更を検知できます。

```jsx filename="app/components/navigation-events.js"
'use client'

import { useEffect } from 'react'
import { usePathname, useSearchParams } from 'next/navigation'

export function NavigationEvents() {
  const pathname = usePathname()
  const searchParams = useSearchParams()

  useEffect(() => {
    const url = `${pathname}?${searchParams}`
    console.log(url)
    // 現在のURLを使用できます
    // ...
  }, [pathname, searchParams])

  return '...'
}
```

レイアウトにインポートして使用できます。

```jsx filename="app/layout.js" highlight={2,10-12}
import { Suspense } from 'react'
import { NavigationEvents } from './components/navigation-events'

export default function Layout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}

        <Suspense fallback={null}>
          <NavigationEvents />
        </Suspense>
      </body>
    </html>
  )
}
```

> **補足**: `<NavigationEvents>` は、[static rendering](/docs/app/guides/caching#static-rendering) 中に [`useSearchParams()`](/docs/app/api-reference/functions/use-search-params) が最も近い `Suspense` boundary までクライアントサイドでのレンダリングを行うようになるため、[`Suspense` boundary](/docs/app/api-reference/file-conventions/loading#examples) でラップされています。詳しくは[こちら](/docs/app/api-reference/functions/use-search-params#behavior)を参照してください。

### ページ先頭へのスクロールを無効化する

デフォルトでは、Next.js は新しいルートに遷移する際にページ先頭までスクロールします。この挙動は、`router.push()` または `router.replace()` に `scroll: false` を渡すことで無効化できます。

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useRouter } from 'next/navigation'

export default function Page() {
  const router = useRouter()

  return (
    <button
      type="button"
      onClick={() => router.push('/dashboard', { scroll: false })}
    >
      Dashboard
    </button>
  )
}
```

```jsx filename="app/example-client-component.jsx" switcher
'use client'

import { useRouter } from 'next/navigation'

export default function Page() {
  const router = useRouter()

  return (
    <button
      type="button"
      onClick={() => router.push('/dashboard', { scroll: false })}
    >
      Dashboard
    </button>
  )
}
```
