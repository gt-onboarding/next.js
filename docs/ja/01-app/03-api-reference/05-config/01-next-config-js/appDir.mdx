title: appDir
description: App Router を有効化して、レイアウトやストリーミングなどを利用できるようにします。
version: legacy
---

> **補足**: このオプションは Next.js 13.4 以降では**不要**になりました。App Router は安定版になっています。

App Router（[`app` ディレクトリ](/docs/app)）は、[レイアウト](/docs/app/api-reference/file-conventions/layout)、[サーバーコンポーネント](/docs/app/getting-started/server-and-client-components)、[ストリーミング](/docs/app/api-reference/file-conventions/loading)、および[コンポーネントと同じ場所でのデータフェッチ](/docs/app/getting-started/fetching-data)をサポートします。

`app` ディレクトリを使用すると、[React Strict Mode](https://react.dev/reference/react/StrictMode) が自動的に有効になります。[`app` を段階的に導入する方法](/docs/app/guides/migrating/app-router-migration#migrating-from-pages-to-app)を参照してください。
