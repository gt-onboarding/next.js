## CDN をセットアップする

[CDN](https://en.wikipedia.org/wiki/Content_delivery_network) をセットアップするには、アセットプレフィックスを設定し、CDN のオリジンが Next.js をホストしているドメインを参照するように構成します。

`next.config.mjs` を開き、[phase](/docs/app/api-reference/config/next-config-js#async-configuration) に応じて `assetPrefix` 設定を追加します。

```js filename="next.config.mjs"
// @ts-check
import { PHASE_DEVELOPMENT_SERVER } from 'next/constants'

export default (phase) => {
  const isDev = phase === PHASE_DEVELOPMENT_SERVER
  /**
   * @type {import('next').NextConfig}
   */
  const nextConfig = {
    assetPrefix: isDev ? undefined : 'https://cdn.mydomain.com',
  }
  return nextConfig
}
```

Next.js は、`/_next/` パス（`.next/static/` フォルダー）から読み込む JavaScript と CSS ファイルに対して、自動的にアセットプレフィックスを使用します。たとえば、上記の設定を行った場合、JS チャンクへのリクエストは次のようになります。

```
/_next/static/chunks/4b9b41aaa062cbbfeff4add70f256968c51ece5d.4d708494b3aed70c04f0.js
```

すると、次のようになります。

```
https://cdn.mydomain.com/_next/static/chunks/4b9b41aaa062cbbfeff4add70f256968c51ece5d.4d708494b3aed70c04f0.js
```

特定の CDN にファイルをアップロードする際の具体的な設定は、利用する CDN によって異なります。CDN 上でホストする必要があるのは `.next/static/` の中身のみで、上記の URL リクエストが示すように `_next/static/` としてアップロードする必要があります。**`.next/` フォルダのそれ以外の部分は決してアップロードしないでください。** サーバーコードやその他の設定を公開してはいけないためです。

`assetPrefix` は `_next/static` へのリクエストには適用されますが、次のパスには影響しません:

<AppOnly>
  * [public](/docs/app/api-reference/file-conventions/public-folder)
  フォルダ内のファイル。これらのアセットを CDN
  経由で配信したい場合は、自分でプレフィックスを付与する必要があります。
</AppOnly>

<PagesOnly>
  * [public](/docs/pages/api-reference/file-conventions/public-folder)
  フォルダ内のファイル。これらのアセットを CDN
  経由で配信したい場合は、自分でプレフィックスを付与する必要があります。 *
  `getServerSideProps` ページに対する `/_next/data/`
  リクエスト。これらのリクエストは静的ではないため、常にメインドメインに対して行われます。
  * `getStaticProps` ページに対する `/_next/data/`
  リクエスト。これらのリクエストは、[Incremental Static
  Generation](/docs/pages/guides/incremental-static-regeneration)
  を利用していない場合でも（整合性のため）、常にメインドメインに対して行われます。
</PagesOnly>
