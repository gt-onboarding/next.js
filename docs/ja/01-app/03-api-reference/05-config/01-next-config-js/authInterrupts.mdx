`authInterrupts` 設定オプションを有効にすると、アプリケーション内で [`forbidden`](/docs/app/api-reference/functions/forbidden) と [`unauthorized`](/docs/app/api-reference/functions/unauthorized) の各 API を使用できます。これらの関数は実験的機能であるため、使用するには `next.config.js` ファイルで `authInterrupts` オプションを有効にする必要があります。

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    authInterrupts: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
module.exports = {
  experimental: {
    authInterrupts: true,
  },
}
```
