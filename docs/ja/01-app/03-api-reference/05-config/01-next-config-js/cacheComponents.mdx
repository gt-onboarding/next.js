`cacheComponents` フラグは Next.js の機能であり、App Router でのデータフェッチ処理が、明示的にキャッシュされていない限り事前レンダーの対象から除外されるようにします。これは、サーバーコンポーネントでの動的なデータフェッチのパフォーマンス最適化に役立ちます。

アプリケーションが、事前レンダー済みキャッシュからの提供ではなく、実行時に常に最新のデータフェッチを行う必要がある場合に有用です。

このフラグは、[`use cache`](/docs/app/api-reference/directives/use-cache) と組み合わせて使用されることを想定しています。これにより、ページ、関数、またはコンポーネント単位で `use cache` を使用してキャッシュする特定の箇所を定義しない限り、データフェッチはデフォルトで実行時に行われます。

## 使用方法

`cacheComponents` フラグを有効にするには、`next.config.ts` ファイルで `true` に設定します。

```ts filename="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,
}

export default nextConfig
```

`cacheComponents` が有効になっている場合、次のキャッシュ関連の関数と設定を使用できます:

- [`use cache` ディレクティブ](/docs/app/api-reference/directives/use-cache)
- `use cache` と併用する [`cacheLife` 関数](/docs/app/api-reference/config/next-config-js/cacheLife)
- [`cacheTag` 関数](/docs/app/api-reference/functions/cacheTag)

## 注意事項

- `cacheComponents` は、ランタイムに最新のデータをフェッチすることでパフォーマンスを最適化できますが、事前レンダリングされたコンテンツを返す場合と比べて、追加のレイテンシが発生する可能性があります。
