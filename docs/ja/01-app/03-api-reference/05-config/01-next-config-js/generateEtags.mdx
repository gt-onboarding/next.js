Next.js はデフォルトで、すべてのページに対して [ETag](https://en.wikipedia.org/wiki/HTTP_ETag) を生成します。キャッシュ戦略によっては、HTML ページでの ETag 生成を無効化したい場合があります。

`next.config.js` を開き、`generateEtags` オプションを無効にします。

```js filename="next.config.js"
module.exports = {
  generateEtags: false,
}
```
