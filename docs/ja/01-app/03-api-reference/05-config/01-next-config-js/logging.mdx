## オプション

<AppOnly>

### フェッチ

開発モードで Next.js を実行しているときに、ログレベルと完全な URL をコンソールに出力するかどうかを設定できます。

```js filename="next.config.js"
module.exports = {
  logging: {
    fetches: {
      fullUrl: true,
    },
  },
}
```

[サーバーコンポーネントの HMR キャッシュ](/docs/app/api-reference/config/next-config-js/serverComponentsHmrCache) から復元される `fetch` リクエストは、デフォルトではログに記録されません。ただし、`logging.fetches.hmrRefreshes` を `true` に設定することで有効化できます。

```js filename="next.config.js"
module.exports = {
  logging: {
    fetches: {
      hmrRefreshes: true,
    },
  },
}
```

### サーバー関数

開発中は、[サーバー関数](https://react.dev/reference/rsc/server-functions) の呼び出しがデフォルトでログに記録されます。これを無効にするには、`logging.serverFunctions` を `false` に設定します。

```js filename="next.config.js"
module.exports = {
  logging: {
    serverFunctions: false,
  },
}
```

有効になっている場合、ターミナルには各サーバー関数の呼び出しが、その関数名、引数、および実行時間とともに表示されます:

```bash filename="Terminal"
POST /
  └─ ƒ myAction(arg1, arg2) in 5ms app/actions.ts
```

</AppOnly>

### 受信リクエスト

デフォルトでは、開発中はすべての受信リクエストがコンソールにログ出力されます。`incomingRequests` オプションを使用して、どのリクエストを無視するかを制御できます。
これは開発時にのみログ出力されるため、このオプションは本番ビルドには影響しません。

```js filename="next.config.js"
module.exports = {
  logging: {
    incomingRequests: {
      ignore: [/\api\/v1\/health/],
    },
  },
}
```

また、`incomingRequests` を `false` に設定すると、受信リクエストのログ記録を無効にできます。

```js filename="next.config.js"
module.exports = {
  logging: {
    incomingRequests: false,
  },
}
```

### ブラウザコンソールログ

開発中に、ブラウザのコンソールログ（`console.log`、`console.warn`、`console.error` など）をターミナルにも出力できます。これにより、ブラウザの開発者ツールを開かなくてもクライアント側のコードをデバッグできます。

```js filename="next.config.js"
module.exports = {
  logging: {
    browserToTerminal: true,
  },
}
```

#### オプション

`browserToTerminal` オプションには、次の値を指定できます。

| 値        | 説明                                                         |
| --------- | ------------------------------------------------------------ |
| `'warn'`  | デフォルトで警告とエラーのみを転送します                     |
| `'error'` | エラーのみを転送します                                       |
| `true`    | すべてのコンソール出力（log, info, warn, error）を転送します |
| `false`   | ブラウザーのログ転送を無効にします                           |

```js filename="next.config.js"
module.exports = {
  logging: {
    browserToTerminal: 'warn',
  },
}
```

#### ソース位置

有効にすると、ブラウザーのログにはデフォルトでソース位置情報（ファイルパスおよび行番号）が含まれます。たとえば次のようになります。

<AppOnly>

```tsx filename="app/page.tsx" highlight={8}
'use client'

export default function Home() {
  return (
    <button
      type="button"
      onClick={() => {
        console.log('Hello World')
      }}
    >
      Click me
    </button>
  )
}
```

ボタンをクリックすると、ターミナルに次のメッセージが出力されます：

```bash filename="Terminal"
[browser] Hello World (app/page.tsx:8:17)
```

</AppOnly>

<PagesOnly>

```tsx filename="pages/index.tsx" highlight={6}
export default function Home() {
  return (
    <button
      type="button"
      onClick={() => {
        console.log('Hello World')
      }}
    >
      Click me
    </button>
  )
}
```

ボタンをクリックすると、ターミナルに次のメッセージが出力されます：

```bash filename="Terminal"
[browser] Hello World (pages/index.tsx:6:17)
```

</PagesOnly>

### ログの無効化

さらに、`logging` を `false` に設定すると、開発時のログ出力を無効化できます。

```js filename="next.config.js"
module.exports = {
  logging: false,
}
```
