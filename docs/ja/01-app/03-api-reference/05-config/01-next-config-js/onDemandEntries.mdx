Next.js には、開発環境でサーバーがビルド済みページをメモリ上に保持するか破棄するかを、ある程度制御できるいくつかのオプションが用意されています。

デフォルト設定を変更するには、`next.config.js` を開き、`onDemandEntries` 設定を追加します。

```js filename="next.config.js"
module.exports = {
  onDemandEntries: {
    // サーバーがページをバッファに保持する期間（ミリ秒単位）
    maxInactiveAge: 25 * 1000,
    // 破棄されずに同時に保持できるページ数
    pagesBufferLength: 2,
  },
}
```
