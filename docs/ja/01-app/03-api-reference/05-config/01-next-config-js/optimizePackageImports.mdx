一部のパッケージは何百、何千ものモジュールをエクスポートする場合があり、これが開発時と本番環境の両方でパフォーマンス上の問題の原因になることがあります。

パッケージを `experimental.optimizePackageImports` に追加すると、実際に使用しているモジュールだけが読み込まれるようになり、多数の名前付きエクスポートを含む import 文を記述できるという利便性はそのまま保てます。

```js filename="next.config.js"
module.exports = {
  experimental: {
    optimizePackageImports: ['package-name'],
  },
}
```
