---
title: reactMaxHeadersLength
description: React によって出力され、レスポンスに追加されるヘッダーの最大長さ。
---

静的レンダリング時に、React はヘッダーを出力し、それをレスポンスに追加できます。これらのヘッダーは、ブラウザにフォント、スクリプト、スタイルシートなどのリソースをプリロードさせることで、パフォーマンスの向上に役立ちます。デフォルト値は `6000` ですが、`next.config.js` の `reactMaxHeadersLength` オプションを設定することでこの値を変更できます。

```js filename="next.config.js"
module.exports = {
  reactMaxHeadersLength: 1000,
}
```

> **参考**: このオプションは App Router でのみ利用できます。

ブラウザとサーバーの間にあるプロキシの種類によっては、ヘッダーが途中で切られてしまうことがあります。たとえば、長いヘッダーをサポートしないリバースプロキシを使用している場合は、ヘッダーが切り捨てられないように、より小さい値を設定する必要があります。
