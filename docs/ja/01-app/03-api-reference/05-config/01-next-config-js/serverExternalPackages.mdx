---
title: serverExternalPackages
description: 特定の依存関係をサーバーコンポーネントのバンドル対象から除外し、ネイティブな Node.js の `require` を使用します。
---

[サーバーコンポーネント](/docs/app/getting-started/server-and-client-components) と [Route Handlers](/docs/app/api-reference/file-conventions/route) 内で使用される依存関係は、Next.js によって自動的にバンドルされます。

依存関係が Node.js 固有の機能を使用している場合、特定の依存関係をサーバーコンポーネントのバンドル対象から除外し、ネイティブな Node.js の `require` を使用するようにできます。

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  serverExternalPackages: ['@acme/ui'],
}

module.exports = nextConfig
```

Next.js には、現在互換性対応を進めており、自動的に除外されている [一般的なパッケージの短いリスト](https://github.com/vercel/next.js/blob/canary/packages/next/src/lib/server-external-packages.jsonc) が含まれています:
