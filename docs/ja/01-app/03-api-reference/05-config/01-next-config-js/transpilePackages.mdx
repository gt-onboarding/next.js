Next.js は、ローカルパッケージ（モノレポなど）や外部依存パッケージ（`node_modules`）を自動的にトランスパイルしてバンドルできます。これにより、`next-transpile-modules` パッケージは不要になります。

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  transpilePackages: ['package-name'],
}

module.exports = nextConfig
```
