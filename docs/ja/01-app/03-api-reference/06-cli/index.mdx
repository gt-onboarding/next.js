Next.js には、**2 つ**のコマンドラインインターフェイス (CLI) ツールが含まれています:

- **`create-next-app`**: デフォルトのテンプレート、または公開 GitHub リポジトリ上の[サンプル](https://github.com/vercel/next.js/tree/canary/examples)を使って、新しい Next.js アプリケーションをすばやく作成できます。
- **`next`**: Next.js の開発サーバーを起動したり、アプリケーションをビルドしたりといった操作を行えます。
