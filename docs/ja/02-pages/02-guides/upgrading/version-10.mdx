---
title: バージョン 10 へのアップグレード方法
nav_title: バージョン 10
description: Next.js アプリケーションをバージョン 9 からバージョン 10 にアップグレードします。
---

バージョン 9 と 10 の間に互換性を損なう変更はありません。

バージョン 10 にアップグレードするには、次のコマンドを実行します。

```bash filename="Terminal"
npm i next@10
```

```bash filename="Terminal"
yarn add next@10
```

```bash filename="Terminal"
pnpm up next@10
```

```bash filename="Terminal"
bun add next@10
```

> **補足:** TypeScript を使用している場合は、`@types/react` と `@types/react-dom` もあわせて対応するバージョンにアップグレードしてください。
