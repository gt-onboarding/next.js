---
title: カスタム Document
description: Next.js によって追加されるデフォルトのドキュメントのマークアップを拡張します。
---

カスタム `Document` を使用すると、[Page](/docs/pages/building-your-application/routing/pages-and-layouts) をレンダーするときに使用される `<html>` と `<body>` タグを更新できます。

デフォルトの `Document` をオーバーライドするには、次のように `pages/_document` ファイルを作成します：

```tsx filename="pages/_document.tsx" switcher
import { Html, Head, Main, NextScript } from 'next/document'

export default function Document() {
  return (
    <Html lang="en">
      <Head />
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  )
}
```

```jsx filename="pages/_document.jsx" switcher
import { Html, Head, Main, NextScript } from 'next/document'

export default function Document() {
  return (
    <Html lang="en">
      <Head />
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  )
}
```

> **補足**:
>
> - `_document` はサーバー上でのみレンダリングされるため、このファイル内では `onClick` などのイベントハンドラーは使用できません。
> - ページが正しくレンダリングされるには、`<Html>`、`<Head />`、`<Main />`、`<NextScript />` が必要です。

## 注意点

- `_document` で使用される `<Head />` コンポーネントは、[`next/head`](/docs/pages/api-reference/components/head) とは同じものではありません。ここで使用される `<Head />` コンポーネントは、すべてのページに共通する `<head>` 内のコードにのみ使用してください。それ以外のケース、たとえば `<title>` タグなどについては、ページやコンポーネント内で [`next/head`](/docs/pages/api-reference/components/head) を使用することを推奨します。
- `<Main />` の外側にある React コンポーネントはブラウザによって初期化されません。ここにアプリケーションロジックやカスタム CSS（`styled-jsx` など）を追加しないでください。すべてのページで共有するコンポーネント（メニューやツールバーなど）が必要な場合は、代わりに [Layouts](/docs/pages/building-your-application/routing/pages-and-layouts#layout-pattern) を参照してください。
- `Document` は現在、[`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props) や [`getServerSideProps`](/docs/pages/building-your-application/data-fetching/get-server-side-props) のような Next.js の [データ取得メソッド](/docs/pages/building-your-application/data-fetching) をサポートしていません。

## `renderPage` のカスタマイズ

`renderPage` のカスタマイズは高度な使い方であり、CSS-in-JS のようなライブラリでサーバーサイドレンダリングをサポートする場合にのみ必要です。組み込みの `styled-jsx` サポートでは必要ありません。

**このパターンの使用は推奨しません。** 代わりに、ページやレイアウトでのデータ取得をより簡単に行える App Router を [段階的に採用](/docs/app/guides/migrating/app-router-migration) することを検討してください。

```tsx filename="pages/_document.tsx" switcher
import Document, {
  Html,
  Head,
  Main,
  NextScript,
  DocumentContext,
  DocumentInitialProps,
} from 'next/document'

class MyDocument extends Document {
  static async getInitialProps(
    ctx: DocumentContext
  ): Promise<DocumentInitialProps> {
    const originalRenderPage = ctx.renderPage

    // Reactのレンダリングロジックを同期的に実行する
    ctx.renderPage = () =>
      originalRenderPage({
        // Reactツリー全体をラップする際に便利
        enhanceApp: (App) => App,
        // ページ単位でラップする際に便利
        enhanceComponent: (Component) => Component,
      })

    // 親の`getInitialProps`を実行する。カスタム`renderPage`が含まれるようになっている
    const initialProps = await Document.getInitialProps(ctx)

    return initialProps
  }

  render() {
    return (
      <Html lang="en">
        <Head />
        <body>
          <Main />
          <NextScript />
        </body>
      </Html>
    )
  }
}

export default MyDocument
```

```jsx filename="pages/_document.jsx" switcher
import Document, { Html, Head, Main, NextScript } from 'next/document'

class MyDocument extends Document {
  static async getInitialProps(ctx) {
    const originalRenderPage = ctx.renderPage

    // Reactのレンダリングロジックを同期的に実行する
    ctx.renderPage = () =>
      originalRenderPage({
        // Reactツリー全体をラップする際に便利
        enhanceApp: (App) => App,
        // ページ単位でラップする際に便利
        enhanceComponent: (Component) => Component,
      })

    // 親の`getInitialProps`を実行する。カスタム`renderPage`が含まれるようになった
    const initialProps = await Document.getInitialProps(ctx)

    return initialProps
  }

  render() {
    return (
      <Html lang="en">
        <Head />
        <body>
          <Main />
          <NextScript />
        </body>
      </Html>
    )
  }
}

export default MyDocument
```

> **補足**:
>
> - `_document` 内の `getInitialProps` は、クライアントサイド遷移の際には呼び出されません。
> - `_document` の `ctx` オブジェクトは、[`getInitialProps`](/docs/pages/api-reference/functions/get-initial-props#context-object) で受け取るものと同等で、さらに `renderPage` が追加されています。
