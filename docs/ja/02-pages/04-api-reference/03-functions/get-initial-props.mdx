---
title: getInitialProps
description: getInitialProps を使用して、サーバー上で React コンポーネント用の動的データをフェッチします。
---

> **補足**: `getInitialProps` はレガシー API です。代わりに [`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props) または [`getServerSideProps`](/docs/pages/building-your-application/data-fetching/get-server-side-props) の使用を推奨しています。

`getInitialProps` は、ページのデフォルトエクスポートである React コンポーネントに追加できる `async` 関数です。これはサーバーサイドで実行されるだけでなく、ページ遷移時にはクライアントサイドでも再度実行されます。関数の実行結果は `props` として React コンポーネントに渡されます。

```tsx filename="pages/index.tsx" switcher
import { NextPageContext } from 'next'

Page.getInitialProps = async (ctx: NextPageContext) => {
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const json = await res.json()
  return { stars: json.stargazers_count }
}

export default function Page({ stars }: { stars: number }) {
  return stars
}
```

```jsx filename="pages/index.js" switcher
Page.getInitialProps = async (ctx) => {
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const json = await res.json()
  return { stars: json.stargazers_count }
}

export default function Page({ stars }) {
  return stars
}
```

> **補足**:
>
> - `getInitialProps` から返されるデータは、サーバーサイドレンダリング時にシリアライズされます。`getInitialProps` から返すオブジェクトはプレーンな `Object` にし、`Date`、`Map`、`Set` などは使用しないでください。
> - 初回ページロード時は、`getInitialProps` はサーバー上でのみ実行されます。[`next/link`](/docs/pages/api-reference/components/link) コンポーネントで別のルートへ遷移した場合や、[`next/router`](/docs/pages/api-reference/functions/use-router) を使用した場合は、`getInitialProps` はクライアント上でも実行されます。
> - カスタム `_app.js` 内で `getInitialProps` が使用されていて、遷移先のページが `getServerSideProps` を使用している場合、`getInitialProps` はサーバー上で**のみ**実行されます。

## Context オブジェクト

`getInitialProps` は `context` と呼ばれる 1 つの引数を受け取ります。これは次のプロパティを持つオブジェクトです:

| 名前       | 説明                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| `pathname` | 現在のルート。`/pages` ディレクトリ内のページのパス                                                     |
| `query`    | URL のクエリ文字列。オブジェクトとしてパースされた値                                                    |
| `asPath`   | ブラウザに表示される実際のパス（クエリを含む）を表す `String`                                           |
| `req`      | [HTTP request object](https://nodejs.org/api/http.html#http_class_http_incomingmessage)（サーバーのみ） |
| `res`      | [HTTP response object](https://nodejs.org/api/http.html#http_class_http_serverresponse)（サーバーのみ） |
| `err`      | レンダリング中にエラーが発生した場合のエラーオブジェクト                                                |

## 注意事項

- `getInitialProps` は `pages/` ディレクトリ直下のトップレベルファイルでのみ使用でき、ネストされたコンポーネント内では使用できません。コンポーネント単位でネストされた形でデータ取得を行いたい場合は、[App Router](/docs/app/getting-started/fetching-data) の利用を検討してください。
- ルートが静的か動的かに関わらず、`getInitialProps` から `props` として返されたデータは、初期 HTML 内でクライアント側から参照可能になります。これはページを正しく[ハイドレート](https://react.dev/reference/react-dom/hydrate)できるようにするためです。`props` には、クライアントから参照できるべきでない機密情報を渡さないように注意してください。
