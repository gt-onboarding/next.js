`useSearchParams` は、現在の URL の**クエリ文字列**を読み取るためのフックです。

`useSearchParams` は、[`URLSearchParams`](https://developer.mozilla.org/docs/Web/API/URLSearchParams) インターフェイスの**読み取り専用の**バージョンを返します。

```tsx filename="pages/dashboard.tsx" switcher
import { useSearchParams } from 'next/navigation'

export default function Dashboard() {
  const searchParams = useSearchParams()

  if (!searchParams) {
    // search params がまだ利用可能でない間はフォールバック UI をレンダリングする
    return null
  }

  const search = searchParams.get('search')

  // URL -> `/dashboard?search=my-project`
  // `search` -> 'my-project'
  return <>Search: {search}</>
}
```

```jsx filename="pages/dashboard.js" switcher
import { useSearchParams } from 'next/navigation'

    // search params がまだ利用可能でない間はフォールバック UI をレンダリングする

  }

  // URL -> `/dashboard?search=my-project`
  // `search` -> 'my-project'
  return <>Search: {search}</>
}
```

## パラメータ

```tsx
const searchParams = useSearchParams()
```

`useSearchParams` は引数を取りません。

## 戻り値

`useSearchParams` は、[`URLSearchParams`](https://developer.mozilla.org/docs/Web/API/URLSearchParams) インターフェイスの **読み取り専用** バージョン、または [プリレンダリング](#behavior-during-pre-rendering) 中は `null` を返します。

このインターフェイスには、URL のクエリ文字列を読み取るためのユーティリティメソッドが含まれています:

- [`URLSearchParams.get()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/get): 指定した検索パラメータに対応する最初の値を返します。例:

  | URL                  | `searchParams.get("a")`                                                                                                         |
  | -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
  | `/dashboard?a=1`     | `'1'`                                                                                                                           |
  | `/dashboard?a=`      | `''`                                                                                                                            |
  | `/dashboard?b=3`     | `null`                                                                                                                          |
  | `/dashboard?a=1&a=2` | `'1'` _- すべての値を取得するには [`getAll()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/getAll) を使用します_ |

- [`URLSearchParams.has()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/has): 指定したパラメータが存在するかどうかを示す真偽値を返します。例:

  | URL              | `searchParams.has("a")` |
  | ---------------- | ----------------------- |
  | `/dashboard?a=1` | `true`                  |
  | `/dashboard?b=3` | `false`                 |

- [`getAll()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/getAll)、[`keys()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/keys)、[`values()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/values)、[`entries()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/entries)、[`forEach()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/forEach)、[`toString()`](https://developer.mozilla.org/docs/Web/API/URLSearchParams/toString) など、[`URLSearchParams`](https://developer.mozilla.org/docs/Web/API/URLSearchParams) のその他の **読み取り専用** メソッドについても詳しくは参照してください。

> **補足**: `useSearchParams` は [React Hook](https://react.dev/learn#using-hooks) であり、クラスコンポーネントでは使用できません。

## 挙動

### プリレンダリング時の挙動

[静的最適化](/docs/pages/building-your-application/rendering/automatic-static-optimization)されたページ（`getServerSideProps` を使用していない場合）では、プリレンダリング中は `useSearchParams` は `null` を返します。ハイドレーション後、その値は実際の検索パラメーターの値に更新されます。

これは、検索パラメーターがリクエストに依存しており、静的生成の段階では知ることができないためです。

```tsx filename="pages/dashboard.tsx" switcher
import { useSearchParams } from 'next/navigation'

export default function Dashboard() {
  const searchParams = useSearchParams()

  if (!searchParams) {
    // 検索パラメータの読み込み中にフォールバックUIを返す
    // これによりハイドレーションの不一致を防ぐ
    return <DashboardSkeleton />
  }

  const search = searchParams.get('search')

  return <>Search: {search}</>
}
```

```jsx filename="pages/dashboard.js" switcher
import { useSearchParams } from 'next/navigation'

export default function Dashboard() {
  const searchParams = useSearchParams()

  if (!searchParams) {
    // 検索パラメータの読み込み中にフォールバックUIを返す

    return <DashboardSkeleton />
  }

  const search = searchParams.get('search')

}
```

### `getServerSideProps` と併用する場合

[`getServerSideProps`](/docs/pages/building-your-application/data-fetching/get-server-side-props) を使用する場合、ページはリクエストごとにサーバーでレンダーされ、`useSearchParams` は実際の検索パラメータを即座に返します。

```tsx filename="pages/dashboard.tsx" switcher
import { useSearchParams } from 'next/navigation'

export default function Dashboard() {
  const searchParams = useSearchParams()

  // getServerSideProps を使用する場合、searchParams は常にサーバー上で利用可能なため、
  // このフォールバックがレンダリングされることはありません。ただし、フォールバックを残しておくことで、
  // getServerSideProps を使用しない他のページでもこのコンポーネントを再利用できます。
  if (!searchParams) {
    return null
  }

  const search = searchParams.get('search')

  return <>Search: {search}</>
}

export async function getServerSideProps() {
  return { props: {} }
}
```

```jsx filename="pages/dashboard.js" switcher
import { useSearchParams } from 'next/navigation'

export default function Dashboard() {
  const searchParams = useSearchParams()

  // getServerSideProps を使用する場合、searchParams は常にサーバー上で利用可能なため、
  // このフォールバックはレンダリングされません。ただし、フォールバックを残しておくことで、
  // getServerSideProps を使用しない他のページでもこのコンポーネントを再利用できます。
  if (!searchParams) {
    return null
  }

  const search = searchParams.get('search')

  return <>Search: {search}</>
}

export async function getServerSideProps() {
  return { props: {} }
}
```

## 使用例

### 検索パラメータの更新

[`useRouter`](/docs/pages/api-reference/functions/use-router) フックを使って検索パラメータを更新できます。

```tsx filename="pages/dashboard.tsx" switcher
import { useRouter } from 'next/router'
import { useSearchParams } from 'next/navigation'
import { useCallback } from 'react'

export default function Dashboard() {
  const router = useRouter()
  const searchParams = useSearchParams()

  const createQueryString = useCallback(
    (name: string, value: string) => {
      const params = new URLSearchParams(searchParams?.toString())
      params.set(name, value)
      return params.toString()
    },
    [searchParams]
  )

  if (!searchParams) {
    return null
  }

  return (
    <>
      <p>Sort By</p>
      <button
        onClick={() => {
          router.push(router.pathname + '?' + createQueryString('sort', 'asc'))
        }}
      >
        ASC
      </button>
      <button
        onClick={() => {
          router.push(router.pathname + '?' + createQueryString('sort', 'desc'))
        }}
      >
        DESC
      </button>
    </>
  )
}
```

### App Router でコンポーネントを共有する

`next/navigation` の `useSearchParams` は、Pages Router と App Router の両方で動作します。これにより、どちらのルーターでも利用できる共通コンポーネントを作成できます。

```tsx filename="components/search-bar.tsx" switcher
import { useSearchParams } from 'next/navigation'

// このコンポーネントは pages/ と app/ の両方で動作します
export function SearchBar() {
  const searchParams = useSearchParams()

  if (!searchParams) {
    // プリレンダリング中の Pages Router 向けフォールバック
    return <input defaultValue="" placeholder="Search..." />
  }

  const search = searchParams.get('search') ?? ''

  return <input defaultValue={search} placeholder="Search..." />
}
```

```jsx filename="components/search-bar.js" switcher
import { useSearchParams } from 'next/navigation'

// このコンポーネントは pages/ と app/ の両方で動作します
export function SearchBar() {
  const searchParams = useSearchParams()

  if (!searchParams) {
    // プリレンダリング中の Pages Router 向けフォールバック
    return <input defaultValue="" placeholder="Search..." />
  }

  const search = searchParams.get('search') ?? ''

  return <input defaultValue={search} placeholder="Search..." />
}
```

> **補足**: App Router でこのコンポーネントを使用する場合は、[静的レンダリング](/docs/app/api-reference/functions/use-search-params#static-rendering) をサポートするために `<Suspense>` バウンダリでラップしてください。
