title: serverExternalPackages
description: '`bundlePagesRouterDependencies` で有効になる依存関係バンドルから、特定の依存関係を除外します。'
---

[`bundlePagesRouterDependencies`](/docs/pages/api-reference/config/next-config-js/bundlePagesRouterDependencies) オプションによる自動バンドルから、特定の依存関係を除外します。

これらのページでは、その依存関係を解決するために、Node.js 標準の `require` が使用されます。

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  serverExternalPackages: ['@acme/ui'],
}

module.exports = nextConfig
```

Next.js には、現在互換性対応を進めており、自動的に除外されている [一部の代表的な人気パッケージの短いリスト](https://github.com/vercel/next.js/blob/canary/packages/next/src/lib/server-external-packages.jsonc) が含まれます：
