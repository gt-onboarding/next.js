> 現在表示しているのは Pages Router のドキュメントです。最新の機能については [App Router](/docs/app) のドキュメントを参照してください。

**Pages Router** は、直感的なファイルシステムベースのルーターを使用して、各ファイルをルートにマッピングします。

Next.js 13 以前は、Pages Router が Next.js でルートを作成する主な方法でした。Pages Router は以降のバージョンの Next.js でも引き続きサポートされていますが、React の最新機能を活用するために、新しい [App Router](/docs/app) への移行を推奨します。
