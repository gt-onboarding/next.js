Next.js は、**モダンブラウザー**を設定不要でサポートします。

- Chrome 111+
- Edge 111+
- Firefox 111+
- Safari 16.4+

## Browserslist

特定のブラウザや機能を対象にしたい場合、Next.js は `package.json` ファイル内での [Browserslist](https://browsersl.ist) の設定をサポートしています。Next.js はデフォルトで、次の Browserslist の設定を使用します。

```json filename="package.json"
{
  "browserslist": ["chrome 111", "edge 111", "firefox 111", "safari 16.4"]
}
```

## ポリフィル

Next.js では [広く利用されているポリフィル](https://github.com/vercel/next.js/blob/canary/packages/next-polyfill-nomodule/src/index.js)を自動的に読み込みます。例えば次のようなものが含まれます:

- [**fetch()**](https://developer.mozilla.org/docs/Web/API/Fetch_API) — 置き換え対象: `whatwg-fetch` および `unfetch`。
- [**URL**](https://developer.mozilla.org/docs/Web/API/URL) — 置き換え対象: [`url` パッケージ (Node.js API)](https://nodejs.org/api/url.html)。
- [**Object.assign()**](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Object/assign) — 置き換え対象: `object-assign`、`object.assign`、`core-js/object/assign`。

依存パッケージにこれらのポリフィルが含まれている場合、重複を避けるため本番ビルドから自動的に除外されます。

さらにバンドルサイズを削減するため、Next.js はこれらのポリフィルを必要とするブラウザに対してのみ読み込みます。世界全体のウェブトラフィックの大部分では、これらのポリフィルはダウンロードされません。

### カスタムポリフィル

自分のコードや外部の npm 依存関係が、対象ブラウザ（IE 11 など）でサポートされていない機能を必要とする場合は、自分でポリフィルを追加する必要があります。

#### App Router での利用

ポリフィルを利用するには、[`instrumentation-client.js`](/docs/app/api-reference/file-conventions/instrumentation-client) ファイルにインポートします。

```ts filename="instrumentation-client.ts"
import './polyfills'
```

#### Pages Router を使用する場合

この場合は、必要な**特定のポリフィル**を、[Custom `<App>`](/docs/pages/building-your-application/routing/custom-app) または個々のコンポーネント内でトップレベルにインポートしてください。

```tsx filename="pages/_app.tsx" switcher
import './polyfills'

import type { AppProps } from 'next/app'

export default function MyApp({ Component, pageProps }: AppProps) {
  return <Component {...pageProps} />
}
```

```jsx filename="pages/_app.jsx" switcher
import './polyfills'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

#### ポリフィルの条件付き読み込み

最適なアプローチは、サポートされていない機能の使用箇所を特定の UI セクションに切り出し、必要に応じてポリフィルを条件付きで読み込むことです。

```ts filename="hooks/analytics.ts" switcher
import { useCallback } from 'react'

export const useAnalytics = () => {
  const tracker = useCallback(async (data: unknown) => {
    if (!('structuredClone' in globalThis)) {
      import('polyfills/structured-clone').then((mod) => {
        globalThis.structuredClone = mod.default
      })
    }

    /* structured clone を使用する処理を行う */
  }, [])

  return tracker
}
```

```js filename="hooks/analytics.js" switcher

    /* structured clone を使用する処理を行う */
  }, [])

  return tracker
}
```

## JavaScript の言語機能

Next.js では、最新の JavaScript 機能をすぐに利用できます。[ES6 の機能](https://github.com/lukehoban/es6features)に加えて、Next.js は次の機能もサポートしています：

- [Async/await](https://github.com/tc39/ecmascript-asyncawait) (ES2017)
- [Object Rest/Spread Properties](https://github.com/tc39/proposal-object-rest-spread) (ES2018)
- [Dynamic `import()`](https://github.com/tc39/proposal-dynamic-import) (ES2020)
- [Optional Chaining](https://github.com/tc39/proposal-optional-chaining) (ES2020)
- [Nullish Coalescing](https://github.com/tc39/proposal-nullish-coalescing) (ES2020)
- [Class Fields](https://github.com/tc39/proposal-class-fields) と [Static Properties](https://github.com/tc39/proposal-static-class-features) (ES2022)
- などもサポートされています

### TypeScript の機能

Next.js には TypeScript のサポートが標準で組み込まれています。[詳しくはこちら](/docs/pages/api-reference/config/typescript)。
