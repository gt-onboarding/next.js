毎週 500 万回以上ダウンロードされている Next.js には、世界中の開発者による大規模で活発なコミュニティがあります。次のような形でコミュニティに参加できます。

## 貢献

Next.js の開発に貢献する方法はいくつかあります。

- [Documentation](/docs/community/contribution-guide): Next.js の使い方をユーザーがより理解しやすくなるように、改善案を提案したり、新しいセクションを執筆したりできます。
- [Examples](https://github.com/vercel/next.js/tree/canary/examples): 新しいサンプルを作成したり、既存のサンプルを改善したりして、開発者が Next.js を他のツールやサービスと統合できるよう支援できます。
- [Codebase](https://github.com/vercel/next.js/tree/canary/contributing/core): 基盤となるアーキテクチャへの理解を深め、バグや不具合の修正、新機能の提案などに貢献できます。

## ディスカッション

Next.js について質問がある場合や、ほかの開発者を手助けしたい場合は、いつでも以下のコミュニティで議論に参加できます。

- [GitHub Discussions](https://github.com/vercel/next.js/discussions)
- [Discord](https://discord.com/invite/bUG2bvbtHy)
- [Reddit](https://www.reddit.com/r/nextjs)

## ソーシャルメディア

Next.js に関する最新情報は [Twitter](https://x.com/nextjs) をフォローし、Next.js の動画は [Vercel の YouTube チャンネル](https://www.youtube.com/@VercelHQ) をチャンネル登録してご覧ください。

## 行動規範

私たちは、インクルーシブで誰もが歓迎されるコミュニティづくりを重視しています。そのため、すべてのメンバーに対し、[行動規範](https://github.com/vercel/next.js/blob/canary/CODE_OF_CONDUCT.md)に従っていただくようお願いしています。このドキュメントでは、参加者の行動に関する指針と期待事項を定めています。ぜひ一読のうえ、安全で互いを尊重し合える環境の維持にご協力ください。
