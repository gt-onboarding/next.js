## Next.js とは？

Next.js は、フルスタック Web アプリケーションを構築するための React フレームワークです。UI は React コンポーネントで構築し、Next.js が追加の機能と最適化を提供します。

また、バンドラやコンパイラなどの低レベルなツールも自動的に設定します。そのため、プロダクトの開発と迅速なリリースに集中できます。

個人の開発者でも大規模なチームの一員でも、Next.js はインタラクティブで動的かつ高速な React アプリケーションの構築に役立ちます。

## App Router と Pages Router

Next.js には 2 種類のルーターがあります。

- **App Router**: サーバーコンポーネントなどの新しい React 機能をサポートする新しいルーターです。
- **Pages Router**: 元々のルーターで、現在もサポートされており、継続的に改善されています。

サイドバー上部にあるドロップダウンメニューから、[App Router](/docs/app) と [Pages Router](/docs/pages) のドキュメントを切り替えられます。

### React バージョンの扱い

App Router と Pages Router では、React のバージョンの扱いが異なります。

- **App Router**: [React canary releases](https://react.dev/blog/2023/05/03/react-canaries) を組み込みで使用します。これには、すべての安定した React 19 の変更に加えて、次の React リリースに先立ちフレームワーク内で検証されている新機能が含まれます。

- **Pages Router**: プロジェクトの `package.json` にインストールされている React のバージョンを使用します。

このアプローチにより、新しい React の機能が App Router で確実に動作する一方で、既存の Pages Router アプリケーションとの後方互換性も維持されます。

## 事前知識

このドキュメントでは、読者がある程度のウェブ開発の知識を持っていることを前提としています。始める前に、次の内容に慣れているとスムーズです。

- HTML
- CSS
- JavaScript
- React

React が初めての方や復習したい方には、[React Foundations コース](/learn/react-foundations)と、学びながら実際にアプリケーションを構築する [Next.js Foundations コース](/learn/dashboard-app) から始めることをおすすめします。

## アクセシビリティ

スクリーンリーダーを使用する際に最適な体験を得るため、Firefox と NVDA、または Safari と VoiceOver の組み合わせの利用を推奨します。
